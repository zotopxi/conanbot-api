# 🇲🇦 ConanAPI Bot - Moroccan Discord Auditor
A specialized bot for monitoring Moroccan Discord servers with features for voice channels, role permissions, and server analytics.

## 🌟 Features
-  Moroccan voice channel analytics
-  Advanced role permission checks
-  Top Moroccan server rankings
-  User activity monitoring

## 🚀 Quick Start (English)

### Prerequisites
- Node.js v16+
- Discord bot token

### Installation
```bash
# Clone the repository
git clone https://github.com/zotopxi/conanbot-api.git
cd conanbot-api

# Install dependencies
npm install


# Configuration
Create .env file:

TOKEN=your_discord_bot_token_here
PREFIX=!  # Your preferred prefix (e.g., !, ., $)

# Run Bot
Start the bot:
node conan.js
